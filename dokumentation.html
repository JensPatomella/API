API Dokumentation

Routes

GET /

Auth: Nej

Returnerar denna dokumentation.

POST /users

Auth: Nej

Skapar ny användare (passwd hashed SHA256).

Body (JSON):

{"firstname": "Anna", "lastname": "Andersson", "userId": "anna", "passwd": "password"}

POST /login

Auth: Nej

Loggar in och returnerar JWT bearer token.

Body (JSON):

{"userId": "anna", "passwd": "password"}

GET /users

Auth: Ja (Bearer token)

Lista alla eller filtrera användare (?firstname=Anna OR lastname=Berg etc.).

Query params: firstname, lastname, userId, id

GET /users/:id

Auth: Ja

Hämtar specifik user.

PUT /users/:id

Auth: Ja (Bearer token)

Uppdaterar user (notera: passwd inte hashed i update).

Body (JSON): Samma som POST /users

{"firstname":"Nya","lastname":"Namn","userId":"nya","passwd":"newpass"}'
